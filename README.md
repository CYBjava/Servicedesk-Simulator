<h1> Servicedesk-Simulator </h1>

This website provides a simulated help desk environment designed to replicate real-world IT support scenarios.
- It provides a variety of support tickets ranging from security incidents and account or directory issues to networking problems just like in the real world.
- It gives users hand-on experience on ticketing systems and troubleshooting while providing real world IT documentation just like in an organization.
